# Calendar-📅 Real-Time Calendar

A sleek, responsive, and interactive real-time calendar web application built using HTML, CSS, and JavaScript.

The calendar automatically detects the user's current date and highlights today with a glowing circular indicator. Users can navigate between months and select individual dates.

🛠️ Tech Stack

Technology| Purpose
HTML5| Page structure
CSS3| Styling, responsive layout & animations
JavaScript| Calendar logic & real-time date detection

🎨 Design

The UI follows a modern dark futuristic / glassmorphism aesthetic with:

- Dark background
- Rounded calendar cells
- Neon green today indicator
- Soft glow effects
- Minimal navigation controls
- Responsive mobile layout
